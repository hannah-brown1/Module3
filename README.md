# Module 3 – Marine Genomics

## Overview

This repository contains work completed for Module 3 of MB5370 Techniques in Marine Science. The module introduced bioinformatic approaches used to analyse genomic and metagenomic data.

The major analysis focused on the microbial community associated with coral black band disease and involved assembling metagenomic sequence data, assessing genome quality, identifying organisms and examining their potential functional roles.

## Repository contents

The repository contains scripts and outputs from the different stages of the metagenomic workflow, including genome assembly, binning, quality assessment, taxonomic classification and functional annotation.

## Key skills

- Metagenome assembly
- Genome binning
- Genome quality assessment with CheckM
- Taxonomic classification using GTDB-Tk
- Genome annotation
- Functional pathway interpretation
- Working with command-line bioinformatic tools

## Data

The metagenomic sequence data used in this module were provided as part of the MB5370 practical activities. The dataset represented a microbial community associated with coral black band disease and was used throughout the bioinformatics workflow.
